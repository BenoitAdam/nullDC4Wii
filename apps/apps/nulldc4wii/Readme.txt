Install :
=========

The app runs from an SD card or from a USB drive - install it on whichever
one you like. Everything it loads (BIOS, presets, saves) is found relative to
the folder boot.dol was launched from, so both work the same way.

BIOS :
======

Wii, SD install :
SD:/apps/nullDC4wii/data/

Wii, USB install :
USB:/apps/nullDC4wii/data/

Dolphin :
SD:/data/

Preset file :
============

Put game_presets.cfg next to boot.dol (SD:/apps/nullDC4wii/ or
USB:/apps/nullDC4wii/), or in your games folder - SD:/discs/ still works.


Game files :
============

Put your games in SD:/discs or USB:/Dreamcast.
Either folder name is accepted on either device (discs or dreamcast), and if
neither exists the browser opens at the root of the card/drive.

The browser starts on the device you launched the app from. Press 2 to
switch between SD and USB.
